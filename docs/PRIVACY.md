# Octane 隐私政策

**最后更新：2026-08-04**

本政策说明 Octane 浏览器扩展（以下简称「本扩展」）如何处理用户数据。安装即视为您已阅读并同意本政策。

## 1. 核心承诺

本扩展遵循**本地优先、用户数据主权**原则：

- **不收集任何个人身份信息**（姓名、邮箱、设备标识等）。
- **不内置任何分析、统计、追踪 SDK**（无 Google Analytics、无埋点、无广告 SDK）。
- **不出售、不共享、不转让**用户数据给任何第三方。
- **加密密钥由您的密码在本地派生，绝不上传、绝不离开您的设备。**

## 2. 数据存储位置

您的全部数据默认存储在**浏览器本地的 IndexedDB** 中，包括：

| 数据 | 说明 | 是否加密 |
|------|------|----------|
| 书签（Bookmark） | URL、标题、描述、标签、图标 | 描述字段可由用户选择加密 |
| 上下文（Context） | 附属于书签的笔记 | 用户可选择加密（AES-GCM） |
| 分类与工作区 | 您自建的分类结构 | 否（仅元数据） |
| 固定标签页 | Pinned tab 配置 | 否（仅元数据） |
| 待办事项（Task） | 任务、清单、任务标签、检查项、优先级、截止日期 | 否（首版本地明文，随备份同步，不进分享包） |
| 标签会话快照 | 开启工作区标签隔离时持续保存的当前工作区标签页与关闭前窗口拓扑（含标签 URL，仅本机） | 否（仅本机，不进备份 / 云同步 / 分享包） |
| 网站图标缓存 | Favicon 本地缓存 | 否（公开图标） |
| 偏好设置 | 上次选中的工作区/分类等 | 否 |

**卸载扩展即彻底清除以上全部本地数据**，无残留。

## 3. 加密机制

对于您标记为加密的上下文笔记：

- 使用浏览器原生 **Web Crypto API**。
- 密钥通过 **PBKDF2** 从您设置的主密码本地派生（迭代次数符合安全标准）。
- 数据以 **AES-GCM** 对称加密后存储。
- **主密码不被存储**；派生密钥仅存于浏览器会话存储，浏览器关闭即清除，从不写入持久存储、从不通过网络发送。

由于密钥不在本扩展掌控之内，**我们无法解密您加密的上下文笔记**——只有持有主密码的您能解开。

## 4. 云同步与第三方服务（可选功能）

云同步是**完全可选**的功能，默认关闭。仅当您主动配置时才会启用。

启用后，本扩展会将备份文件上传到**您本人拥有的云存储**：

| 服务 | 用途 | 访问方式 |
|------|------|----------|
| 阿里云 OSS（`*.aliyuncs.com`） | 备份存储 | 直连您自己的 bucket |
| 腾讯云 COS（`*.myqcloud.com`） | 备份存储 | 直连您自己的 bucket |
| 坚果云 WebDAV（`dav.jianguoyun.com`） | 备份存储 | 直连您的 WebDAV 账号 |

**关键说明：**

- 本扩展**直接与您配置的云存储通信**，云存储凭证（AccessKey / WebDAV 密码）经主密码加密后保存于本地，不上传到任何中间服务器。
- 本扩展**不运营、不拥有任何中转服务器**——您的备份文件从您的浏览器直达您的云存储。
- 通配符域名（`*.aliyuncs.com` / `*.myqcloud.com`）是必需的，因为用户的 OSS/COS bucket 名是动态子域名，扩展无法预知。

## 5. 网站图标（Favicon）获取

为显示书签对应的网站图标，本扩展优先使用本地已缓存的图标。缓存未命中时，可能向以下服务发送该书签的**域名**（仅域名，不含完整 URL、路径或书签内容）：

- 浏览器内置 `_favicon` 端点
- `icon.horse`

此过程只获取公开的图标资源。

## 6. 权限使用说明

| 权限 | 用途 |
|------|------|
| `storage` | 在本地保存您的偏好设置（上次选中的工作区、分类等），以及开启标签隔离时持续保存的工作区标签会话快照（仅本机） |
| `tabs` | 在新标签页展示您打开的标签页列表、标签页与书签匹配、固定标签页功能、侧边栏联动当前页面、标签会话冷恢复 |
| `tabGroups` | 工作区标签隔离时折叠 / 解散 / 恢复标签组，以及冷启动恢复时重建折叠组 |
| `sidePanel` | 提供侧边栏入口，打开网页时自动汇集该书签的上下文 |
| `favicon` | 访问浏览器内置的网站图标端点 |
| `host_permissions`（三个云存储域名） | 仅用于将备份同步到您本人配置的云存储 |

**关于 `tabs` 权限的特别说明：** 本扩展读取标签页信息（URL、标题）仅用于本地展示与书签匹配，**不上传任何标签页数据到任何服务器**。

## 7. 数据留存与删除

- **本地数据**：卸载扩展即全部清除。
- **云端备份**：存储在您的云存储中，您可以随时在云存储管理控制台手动删除，或在本扩展内重新覆盖/删除。

## 8. 数据导出与分享包

本扩展支持两种数据导出,均为**用户主动操作**,扩展不自动传输任何导出文件。

### 全量备份（灾备）

将您的全部书签与待办数据导出为一个 JSON 文件,用于本地备份或上传到您本人的云存储（见第 4 节）。备份文件包含全部书签、上下文、分类、工作区、待办（任务、清单、标签、检查项）;其中您标记为加密的上下文以 AES-GCM 密文形式存储,无主密码无法解密;待办数据为明文存储（与书签元数据一致）。

### 分享包（部分导出/导入）

您可以选取部分工作区或分类,打包成一个分享包 JSON 文件,自行发送给他人;对方在 Octane 中导入即合并到他的书签库（不覆盖对方现有数据）。分享包仅含书签与上下文,待办数据不包含在分享包中（仅随全量备份同步）。

分享包内容取决于您的选择:

- **书签数据（URL、标题、描述、标签、分类结构）始终以明文形式包含在分享包中** —— 请仅分享给您信任的人。
- **上下文笔记二选一**:
  - 不勾选「包含上下文」→ 分享包**不含任何笔记**（仅书签结构,适合分享给同事）。
  - 勾选「包含上下文」→ 分享包含加密笔记（AES-GCM 密文）+ 加密元数据（salt）;**仅当对方设置了与您相同的主密码时才能解密查看**,否则该加密笔记不会导入（仅明文笔记导入,并提示「X 条加密笔记因本机加密设置不同未导入」）。

**关键说明:**

- 分享包是一个普通的 JSON 文件,**由您自行传输**（邮件、聊天、网盘等）,本扩展**不经手、不中转、不上传**分享包到任何服务器。
- 对方导入分享包是**合并追加**,不会覆盖其现有书签。
- 您对分享包的发送对象与传输方式负全部责任。

## 9. 儿童隐私

本扩展不面向 13 岁以下儿童，也不有意收集儿童信息。

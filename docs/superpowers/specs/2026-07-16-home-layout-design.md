
# Home 页面重构设计

日期：2026-07-16

## 目标

保留 home 当前全部功能和业务数据流，仅重构信息层级、布局和视觉样式，使其接近提供的 Speed Shelf 设计稿，并同时适配桌面、窄窗口和移动视口。

## 设计决策

- 采用三层骨架：品牌/高频入口 rail、工作区与分类导航、主内容区。
- 保留现有 `Sidebar`、`Content` 及其子组件的业务职责，不重写 store、service、拖拽和弹窗逻辑。
- 书签仍按当前分类展示为网格；打开标签页仍是独立视图；置顶标签继续属于工作区侧栏并跨分类复用。
- 桌面端使用 68px rail + 222px 导航栏 + 自适应内容区；宽度不足时网格从三列降为两列，再降为单列。
- 移动端隐藏 rail，将工作区/分类导航作为可打开的 Sheet；主内容保留搜索、添加、视图切换和书签操作。

## 视觉系统

沿用 `DESIGN.md` 的品牌规则，不引入设计稿中的蓝色主题：

- accent 使用 `#00B894`，绿底前景使用炭灰 `#2D3436`。
- 内容背景使用冷浅灰，卡片使用白色，边框使用低对比中性灰。
- 侧栏使用炭灰族深色锚定面，选中态使用品牌绿竖条和浅中性底，不依赖绿色大面积铺底。
- 圆角遵循 8/12/16px；层级依靠边框、留白和轻阴影。
- shadcn `--primary` 从当前 neutral 黑色改为品牌绿，`--primary-foreground` 改为炭灰；这改变通用组件的默认颜色但不改变组件 API 或交互契约。

## 组件与兼容边界

- `App.tsx` 保持初始化、解锁和 BroadcastChannel 订阅，仅更新壳层标记和移动端导航状态。
- `Sidebar` 保持工作区、分类、常驻、管理、设置、删除确认和拖拽逻辑，仅调整结构样式。
- `Content` 保持搜索、CRUD、拖拽、打开标签页、上下文和编辑弹窗逻辑，仅调整头部、Tabs 和列表容器。
- 通用 UI 组件只调整 token、默认尺寸、focus/hover 和卡片边框等视觉契约；不得增加 home 专用状态。

## 验证标准

- 桌面端三栏比例、标题/搜索/添加按钮、分类 Tabs 和书签卡片网格与设计稿一致。
- 移动端无横向滚动；导航可打开和关闭；网格与操作目标满足触控尺寸。
- 现有书签、分类、工作区、常驻、标签页、上下文、设置、解锁和拖拽行为保持可用。
- 通过 home 相关测试、`pnpm run typecheck` 和 `pnpm run test`。

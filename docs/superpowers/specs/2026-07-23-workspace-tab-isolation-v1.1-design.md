## 背景与范围

v1（close-only + 手动切换）已 ship 0.2.0.0。v1.1 在「切换行为」设置加两档 hide（折叠），实现「软隔离」：离开工作区时 tab **不关**，折叠为标签组（+ 可选 discard 释放内存），切回时**解散组、tab 释放到顶层**（组仅作切走态临时收纳）。这是用户原始诉求①「切换时隔离（关闭或隐藏，不绝对）」里「隐藏」一支的落地——v1 受 C1（无 chrome.tabs.hide）只交付 close，v1.1 用「折叠 tabGroup + discard」近似 hide。

**v1.1 范围 = 切换行为 2 档 → 4 档**：

| 档位 | 值 | 行为 |
|---|---|---|
| 不隔离（默认） | `off` | 保留所有标签（v1，不变） |
| 自动关闭与恢复 | `close` | 离开关闭，返回重开（v1，不变） |
| **折叠·省内存** | `hide-discard` | 离开折叠为标签组 + discard；返回解散释放 tab（重新加载，页面状态不保留） |
| **折叠·保状态** | `hide` | 离开折叠为标签组；返回解散释放 tab（页面状态保留，占用内存） |

**NOT in v1.1**（移入 TODOS.md）：
- 自动归档（Arc 式 alarms + 窗口 lastActive，跑 MV3 SW）→ 用户决定 v1.1 只做 hide，推迟。
- 同 ws 多窗 session 隔离（session key 加 windowId）→ tension 3 备选方案，记 TODOS 后续评估；v1.1 暂继承 v1「最后归档胜出」已知限制。
- lazy restore / 跨设备 tab 备份 → 同 v1 NOT in scope。

## hide 模型

「tab 不关」前提下的必然结构：**同一窗口多个工作区的标签组共存**（Workona 式）。切走工作区 → 折叠其标签组（discard 档额外卸载内存）；切回 → **解散组、tab 释放到顶层**（组仅作切走态临时收纳，回到工作区即拆）。tab 全程不消失，区别于 close 档的 remove/重开。

切回恢复语义（切回 = 解散组、tab 释放到顶层）：
- 折叠·保状态（hide）：tab 未 discard，解散释放后即恢复，**页面运行时态保留**（表单输入/滚动位置等）。
- 折叠·省内存（hide-discard）：tab 已 discard，解散释放后用户激活时重新加载（页面状态不保留，与 close 档一致）。

## Constraints（继承 v1 + hide 特有）

| # | 约束 | 对策 |
|---|---|---|
| C1 | 无 chrome.tabs.hide()（仅内置扩展） | hide = 折叠 tabGroup + chrome.tabs.discard |
| C3 | tabGroups 三硬伤（groupId 易失/抖动/跨窗口） | **title 拼 workspaceId 哈希标识**（跨重启稳定、重名唯一）+ 两路径回找（见下） |
| C4 | discard 丢页面运行时态 | 折叠·保状态 档不 discard；折叠·省内存 档诚实告知 |
| C4b | Chrome 不允许 pinned tab 加入组 | pinned tab（除 home）在归档档下按 remove 处理（archive 记录 + dispose remove + restore 重开 pinned），无法折叠 |
| C5 | MV3 SW ~30s 回收 | hide 编排仍跑 home 页（与 v1 一致）；自动归档（需 SW）推后 |
| C7 | CWS 隐私画像 | 新增 `tabGroups` 权限（低风险，仅折叠/展开/discard/group） |

## tab 归属语义（codex #2）

**Chrome group membership = tab 的当前工作区归属；散 tab（无 group）= 当前 binding 工作区。**

- hide 模式窗口内 tab 分：当前 ws 的 tab（切回态**散开**，切回即解散组）+ 别 ws 的标识组（折叠）+ 散 tab。
- archive 只取**当前 ws 标识组的 tab + 散 tab**（散 tab 视为当前 ws 用户新开/拖出的）。
- 用户跨组拖拽（把 A 的 tab 拖进 B 组）= **主动重分配归属**，archive 尊重新归属（该 tab 归 B，archive A 时不取）。自洽，不需独立 tab ownership 表。

## 数据模型

```ts
type TabIsolationSetting = 'off' | 'close' | 'hide-discard' | 'hide';
```

**不新增 storage 键**——title 标识作唯一真源（见 C3），去掉 `tabGroupBinding` 映射（codex #1 简化：标识稳定在 title 里，映射冗余）。TabSession 复用 v1（archive 兜底，重启后 restore 源）。

## 权限（codex #10）

manifest（wxt.config.ts）加 `tabGroups`。`chrome.tabs.group`/`ungroup` 同属该能力。`chrome.tabs.discard` 无需额外权限（`tabs` 已有），但只保证「尝试 discard」，不保证 active/受限 tab 成功。需 manifest 变更测试。

## C3 两路径容错（核心，codex #1 定稿）

**标识**：title = `${工作区名} ·${wsHash}`，如 `工作 ·a1b2c3d4`。wsHash = workspaceId 去横线后前 8 位 hex（跨重启稳定、重名工作区唯一）。color 统一 Chrome 内置 grey。

切走/切回工作区 X 时，取其 group：
1. **标识回找（主）**：`chrome.tabGroups.query({windowId:W})` 拿全窗 group → JS 精确匹配 title 以 ` ·${X 的 wsHash}` 结尾 → 命中（唯一）→ 用之。
2. **兜底 restore（找不到时）**：组被删/重启清空/用户改了 title → 按 `TabSession.<X>` 重开 tab + `chrome.tabs.group` 建组 + `tabGroups.update({title:标识, collapsed, color:grey})`。

- 多结果（理论 wsHash 碰撞，8 位 hex 窗口内极低频）→ 视为歧义，走兜底 restore（不任选，codex #1）。
- 用户手动编辑 title 删标识 → 回找不到 → 走兜底 restore 重建（容忍，低频）。
- **孤儿组清理**：ws 删除时（deleteWorkspace hide 分支）清理该 ws 标识组（解散/关闭其 tab），与 v1 delete 清 tabSession 对齐。用户改 title 产生的无标识旧组不自动清理（认不出，用户手动管）。

## 切换编排（Approach A：复用 performSwitch + mode 分支）

`performSwitch` 加 mode 参数。archive 硬屏障 / per-window 串行队列 / 进度事件 / undo 横切逻辑不变（v1 已实现）。按 mode 分流，**失败不静默继续**（codex #5）：

```
performSwitch(toId, W, mode):
  0. 切换前先激活 pinned home（避 active tab 阻塞 discard + 避 restore 抢焦点）   # codex #5
  1. archive（失败 = 硬屏障，不动 tab，Toast 报错中止）—— 所有 mode
     - close：query 全窗 restorable tab
     - hide-discard/hide：当前 ws 标识组的 tab + 散 tab（按归属语义过滤，不取别 ws 组）
       · pinned tab（除 home）记入 session（url+pinned:true），但不进组（C4b）
  2. dispose（按 mode；任一关键操作失败 → 不更新 binding、不完成 select、Toast 报错）# codex #5
     - close：chrome.tabs.remove(contentTabIds)
     - hide-discard：散 tab 先 tabs.group 纳入当前 ws 组 → tabGroups.update(collapsed:true) → 逐 tab tabs.discard
       · discard 单 tab 失败（active/受限/已 discarded）try/catch 跳过，记实际 discard 集
       · discard 部分失败 → 降级为 hide 档语义（折叠但不全 discard），token 记实际状态
     - hide：散 tab 先入组 → tabGroups.update(collapsed:true)（不 discard）
       · pinned tab（除 home）无法折叠 → remove（C4b），切回 restore 重开 pinned
  3. restore（返回 {opened, failed}；binding 只在目标组达到可接受状态后写）        # codex #6
     - close：openTabsInWindow（按 session 重开，active:false）
     - hide-discard/hide：标识回找取 toId 组 → 存在则 tabs.ungroup（解散组、tab 释放到顶层 groupId=-1）
       · 不存在则 openTabsInWindow 重开（不建组，tab 散开；组仅切走态临时收纳）
       · restore 单个 create 失败 → 记 failed，不阻断其余；最终失败集非空 → 保留 session、进 repair 态、Toast 提示
  4. writeBinding(W, toId)（仅 2/3 成功后）
  5. undo token = {fromId, toId, fromName, toName, mode}（undo = 反向切换，见 undo 段）
```

**两条关键正确性约束**：
1. **archive 按归属过滤**（hide）：只存当前 ws 标识组 + 散 tab，避免折叠的别 ws tab 污染当前 session。
2. **散 tab 收纳**（隔离完整性）：dispose 前散 tab 先 tabs.group 纳入当前 ws 组再折叠——否则切走后散 tab 泄漏到目标 ws 视图。

**实现约束**（eng-review CQ1，控圈复杂度）：performSwitch 保持线性编排（archive→dispose→restore→binding），按 mode 拆子函数 `archiveByMode`/`disposeByMode`/`restoreByMode`（内部 close/hide 分流），避免 performSwitch 内联 4 档分支致圈复杂度 >5。tabGroup 标识逻辑（wsHash 派生 + title 格式化/解析 + 标识回找）独立 `src/shared/tabs/tabGroupIdentity.ts`，不混进 performSwitch。

**hide 模式状态机**（eng-review A1，per window；新模型「组」仅切走态临时收纳，切回即解散）：
```
 [binding=X · X tab 散开（切回态）]
      │ 切走→Y
      ▼
 archive X（X 散 tab + 散 tab）──失败──▶ 硬屏障：不折叠/discard，停留 X，Toast 报错
      │ 成功
      ▼
 散 tab tabs.group 建 X 组 ▶ 折叠 X 组 [+discard 档逐 tab discard]
      │
      ▼
 restore Y：标识回找 Y 组 ──命中──▶ ungroup（解散 Y 组，tab 释放到顶层 groupId=-1）
      │                       └─未命中─▶ 兜底 restore（TabSession.Y 重开，不建组，tab 散开）+ 清 Octane 孤儿组
      │ 成功（{opened,failed}，failed 非空进 repair）
      ▼
 binding=Y ──undo（反向切换）──▶ archive Y + dispose Y（建组折叠）+ restore X（解散）+ binding=X
                              （组临时，无 generation 校验，undo 总是反向）
```

## undo（v1.1 rev：入队 + 反向切换；组临时后弃 generation 校验）

undo 走**同一 per-window 串行队列**（不绕过）。新模型「组」仅切走态临时收纳（切回即解散），原 generation 校验失效，改为**反向切换**：
- token = {fromId, toId, fromName, toName, mode}。
- undo = 反向切换（切回源 ws）：手动编排 archive/dispose/restore（不走 performSwitch，避免其 queueUndo 嵌套产生 phantom undo）。源/目标互换：反向源 = 原目标 toId（切回态 tab 散），反向目标 = 原源 fromId（切走态组折叠）。
- undo 语义（按 mode，反向 archive/dispose/restore + 回滚 binding）：
  - close：archive 当前 + remove + restore 源 session + 回滚 binding。
  - hide-discard/hide：archive 当前（散 tab）+ dispose（建组折叠，hide-discard 档 discard）+ restore 源（解散组、tab 散开）+ 回滚 binding。
- 组结构变化不再拒绝 undo（组本就临时，undo 总是反向重建/解散）。

## 跨档切换（codex #3：tension 2 normalize）

**切档 hide→close 时执行一次 normalize**：把窗口内非当前 ws 的标识组 dispose 掉（其 tab 内容已在各自 session），窗口回归 close 的「只剩当前 ws tab」干净语义。之后 close 的 v1 全窗 archive 语义不变（外科手术，不动 v1 close 行为/测试）。

- close→hide / off↔任意：不需 normalize（close 窗口已只有当前 ws tab；off 不碰 tab）。
- 补 `hide→close→hide` 往返测试（验证 normalize 后无 session 污染）。

## 设置 UI（WorkspaceTabsSection）

RadioGroup 2 档 → 4 档。新两档文案（rev5 用户语言「离开时…返回时…」）：
- **折叠·省内存** — 离开时折叠为标签组并释放内存，返回时解散释放 tab（重新加载，页面状态不保留）。
- **折叠·保状态** — 离开时折叠为标签组但保留页面状态，返回时解散释放 tab（占用内存）。

切换确认门控：
- `off → 任一归档档`（close/hide-discard/hide）：弹首启 AlertDialog（复用 `countRestorableTabsInWindow`）。
- **归档档之间互切**（close↔hide-discard↔hide）：直接切，不弹确认（无数据丢失）。hide→close 触发后台 normalize（有 Toast 进度，非阻断确认）。

## 边界 / 错误处理

- **archive 硬屏障**：所有 mode，archive 失败绝不 collapse/discard/remove（v1 安全锚延伸，回归测试守护）。
- **dispose/restore 失败不更新 binding**（codex #5/#6）：collapse/group/discard/create 失败 → 不写 binding、不完成 workspace select、Toast 报错或进 repair 态。源 tab 已折叠/归档时，binding 停留源 ws，用户可重试。
- **切换前激活 pinned home**：避 active tab 在待折叠组致 discard 失败 + 避 restore 抢焦点闪烁。
- **pinned tab**（除 home）：归档档下 archive 记录 + dispose remove + restore 重开（Chrome 禁入组，C4b）；home tab 全程排除。
- **incognito**：hide 不纳入（incognito 窗口不绑定/不隔离，与 v1 一致）。
- **不可恢复散 tab**（devtools:/受限 file:）：不进组、不 dispose；archive 记 url 兜底（切回 restore 尝试，失败跳过）。
- `chrome.tabs.onRemoved` / `tabGroups.onRemoved`（用户手动关组内 tab / 解散组）：标识回找不到 → 下次切回走兜底 restore。
- **多窗口**：tabGroup 天然 per-window，标识回找带 windowId；同 ws 多窗继承 v1「最后归档胜出」已知限制（tension 3，文档强调）。

## 测试（TDD，docs/standards/testing.md 方案 B；codex #9 补全）

- **T0 阻塞前提**（eng-review T1）：`chrome.tabGroups.get/query/update` + `tabs.group/ungroup/discard` 在 fake-browser 是未实现 stub（memory wxt-fake-browser-test-stub）。`tests/setup.ts` beforeEach 须先注入这些实现（FIFO 在 per-test reset 后），否则所有 hide 测试无法跑。

- **逻辑层**：wsHash 派生（稳定性 + 重名唯一）；标识 title 格式化与解析；标识回找（命中/未命中/多结果歧义走兜底）。
- **归属语义**：archive 按标识组 + 散 tab 过滤（hide 不污染别 ws session）；跨组拖拽后 archive 尊重新归属。
- **编排层**：4 档 archive/dispose/restore 分流；切换前激活 home；散 tab 收纳入组；pinned tab（除 home）remove 处理；discard 部分失败降级 hide + token 记实际。
- **失败状态机**（codex #5/#6）：collapse/group/discard 失败 → 不更新 binding；restore 单 create 失败 → failed 集 + repair；archive 硬屏障（hide 模式 archive 失败也不 collapse/discard）。
- **undo**（v1.1 rev）：undo 入 per-window 队列；新模型组临时，undo = 反向切换（总是反转，不拒绝）；hide 保状态 vs discard 重载。
- **跨档**（codex #3）：hide→close normalize 清非当前 ws 组；hide→close→hide 往返无污染；off↔hide↔close 全组合 + 旧 v1 session 兼容。
- **集成**：折叠/解散往返（切回 ungroup 释放 tab）/ 重启标识失效兜底 restore（不建组）/ 用户改 title 删标识 → 兜底 / 手动解散组 / 多窗口独立 / 同 ws 多窗最后归档胜出（已知限制）/ incognito 不纳入。
- **manifest**（codex #10）：wxt.config 加 tabGroups；tabs.group/ungroup/discard/tabGroups.* fake-browser stub 扩展（参考 memory wxt-fake-browser-test-stub）。

## Success Criteria

- hide 档切走折叠、切回解散组（tab 释放到顶层），tab 不关；多 ws 共存互不污染。
- 折叠·省内存 档离开后 tab 内存释放；返回重新加载。
- 折叠·保状态 档返回时页面状态保留。
- 标识失效（重启/改 title）后兜底 restore 不丢 tab；孤儿组（ws 删除）被清理。
- 散 tab 不泄漏到其他 ws 视图（收纳约束成立）。
- archive 硬屏障 / 串行队列（含 undo）/ pinned home 排除 / dispose·restore 失败不更新 binding 全模式成立。
- `pnpm run typecheck` + `pnpm run test` 双绿。

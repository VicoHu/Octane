# Sidebar 分类选中指示条一体化设计

## 背景

当前分类选中态由浅色圆角背景与左侧 3px 品牌绿伪元素组成。伪元素使用右上、右下圆角，导致绿色指示条的外侧仍是直角，视觉上像独立贴附的标记，没有参与选中项的整体圆角轮廓。

## 目标

让绿色指示条与选中背景共用左侧外轮廓，形成一体化选中态，同时保持 `DESIGN.md` 规定的“左 3px 品牌绿竖条 + 极轻中性底”。

## 方案

保留 `.catActive::before`，仅调整圆角方向：

- 宽度继续使用 3px，颜色继续引用 `var(--primary)`。
- 位置继续贴合选中项左边缘并覆盖完整高度。
- 左上、左下圆角使用 `var(--radius-sm)`，与父级 `.cat` 的圆角一致。
- 右上、右下保持直角，使指示条与背景的分界清晰。

不改 DOM、分类项尺寸、padding、背景、hover、拖拽和删除操作。

## 备选方案

1. 保持现有内侧 2px 圆角：改动为零，但不能解决指示条与背景割裂的问题。
2. 改为真实 `border-left`：边框可参与圆角，但会占用盒模型宽度并需要补偿 padding，改动范围更大。

采用伪元素外侧圆角方案，因为它直接修正视觉问题且不影响布局。

## 验证

- CSS 中指示条左侧圆角与 `.cat` 共用 `var(--radius-sm)`，右侧为直角。
- Sidebar 分类交互测试通过。
- `pnpm run typecheck` 与 `pnpm run test` 通过。
- 在浏览器中确认选中态左上、左下轮廓连续，指示条不再像独立元素。

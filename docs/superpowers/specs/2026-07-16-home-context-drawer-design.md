# Home 上下文抽屉视觉统一设计

## 背景

Home 页书签上下文抽屉当前固定为 `500px`，在桌面视口中编辑空间不足；抽屉内部的标题、列表、编辑器密度和页面层级也与 Home 主内容区不一致。本次调整依据 `DESIGN.md`，统一上下文列表态、空状态、错误态和编辑态，并为移动端提供适合长文本编辑的覆盖层形态。

## 目标

- 桌面端为上下文列表和 Markdown 编辑提供 `1000px` 的工作空间；视口不足时铺满可用宽度。
- 移动端改为从底部进入的全屏 Drawer，避免软键盘进一步压缩窄侧栏。
- 让抽屉的背景、间距、边框、圆角、字号和品牌色使用方式与 Home 保持一致。
- 列表态与编辑态使用同一套单栏内容网格，避免进入编辑器时产生视觉跳变。
- 保持现有上下文数据流、自动保存、加密校验和 Markdown 预览行为。

## 方案选择

采用“单栏工作区”方案：列表态和编辑态在同一区域原位切换。

未采用桌面双栏方案，因为它会改变现有导航模型，并要求移动端维护不同的信息结构。未采用居中卡片方案，因为它会形成抽屉内嵌卡片，与 Home 的平铺工作区语言不一致。

## 响应式外壳

- 桌面端（`>= 768px`）使用右侧 `Sheet`，宽度为 `min(1000px, 100vw)`，高度铺满视口。
- 移动端（`< 768px`）使用底部 `Drawer`，高度为 `100dvh`，宽度铺满视口。
- 移动端处理安全区内边距；抽屉内容使用动态视口单位，避免地址栏和软键盘造成布局溢出。
- `ContextList` 根据媒体查询选择外壳，Sheet 与 Drawer 复用同一份面板内容，不复制加载、创建、删除或编辑状态。
- 保留覆盖层的 Escape、遮罩关闭、焦点管理和可访问标题。

## 布局与视觉层级

- 外壳使用 Home 的 `content-bg`，顶部标题区、重复列表项和必要的操作面使用 `card-bg`。
- 桌面内容内边距为 `32px`，移动端为 `16px`；列表态和编辑态共享该内容网格。
- 标题区保持紧凑，使用 `title-sm` 层级，不复用 Home 主页面的展示级字号。
- 列表项作为重复内容使用白色背景、语义边框和 `8px` 圆角；hover 使用中性底色，当前操作最多保留一个绿色焦点。
- 编辑器保持平铺，不额外包裹卡片。标题输入、加密开关、Tabs 和正文区域按垂直节奏排列。
- 列表态的新增按钮位于稳定的底部操作区；编辑态的正文区域占满剩余高度并独立滚动。
- 移动端顶部操作允许换行，所有文字、按钮和状态标签不得互相遮挡。
- 所有颜色、字号、间距、圆角和阴影映射到 `DESIGN.md` 的语义 token，不新增主题值。

## 组件边界

- `ContextList` 继续负责上下文加载、创建、删除、编辑态切换和关闭行为。
- 响应式外壳只负责在桌面 Sheet 与移动 Drawer 之间切换。
- 列表、加载、错误、空状态、编辑器和底部操作区作为共享面板内容渲染。
- `ContextEditor` 继续负责标题、正文、加密状态、编辑/预览 Tabs 和保存状态。
- 优先复用现有 shadcn/ui `Sheet`、`Button`、`Input`、`Textarea`、`Switch`、`Tabs`、`Empty` 和 `AlertDialog`；移动端 Drawer 通过 shadcn registry 引入。
- 样式限制在 ContextList、ContextEditor 及必要的响应式外壳范围内，不修改全局主题 token。

## 交互与数据流

- 保留现有 1 秒防抖自动保存和“保存中 / 已保存 / 未保存”状态。
- 保留加密开关的解锁校验及失败 Toast。
- 保留 Markdown 编辑与预览切换。
- 保留从编辑态返回列表后重新加载上下文的行为。
- 保留创建、删除、错误重试和删除确认流程。
- 不修改 Context Service、Zustand store、IndexedDB、加密逻辑或数据结构。

## 测试与验收

- 按 TDD 先添加失败测试，再实现响应式外壳和视觉结构。
- ContextList 测试覆盖桌面 `1000px` Sheet、移动端全高底部 Drawer，以及两种外壳共享列表和编辑内容。
- ContextEditor 测试覆盖可访问控件、编辑/预览切换和现有返回行为；测试使用真实 UI 组件、`userEvent` 和 jest-dom matcher。
- 执行定向测试、`pnpm run typecheck` 和 `pnpm run test`。
- 在真实浏览器中检查至少 `1440 × 900`、不足 `1000px` 的窄桌面和 `390 × 844` 移动视口。
- 浏览器验收确认：桌面宽度正确、窄视口铺满、移动端从底部全屏进入、内容滚动正常、软键盘友好、文字与控件无重叠。
- 截图对照 Home 页，确认背景、边框、圆角、字号、间距和绿色焦点一致。

## 非目标

- 不新增上下文类型或编辑功能。
- 不修改自动保存时机、关闭时的保存策略或错误恢复策略。
- 不重构 Context Service、store 或加密流程。
- 不调整 Home 页其他区域或全局组件默认尺寸。

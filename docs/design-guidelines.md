# Octane 前端设计规范（Design Guidelines）

> **立场（重要）**：本文件以**审视视角**决定"应该怎样"，是**规范性（prescriptive）**文档，不是对现有代码的描述。
> **现状只是输入之一，且可能本身不合适**——凡现状与规范判定冲突处，以规范为准，差异统一登记在 **§12 设计债务清单**。
> **与其他文档的关系**：`docs/semi-design-spec.md` = Semi 工具 token 手册（通用机制）；`docs/brand-color-migration-guide.md` = 品牌绿迁移实施依据；`docs/home-design-review.md` = 首页评审与理由。
> **口径**：样式一律引用 token，禁止裸写；改主题只动 token 不动组件。
> **参考来源**：结构参考通用前端设计规范要求（[ChatGPT 分享页](https://chatgpt.com/s/t_6a43ec34081c81918098126efd625156)，需登录、条目未取到，按业界通用结构 + 审视判定落地）。

## 1. 品牌基石（Brand Foundation）

一切决策的标尺是 Logo（`public/icons/icon-128.png`）。设计 DNA：

> **克制双色 · 几何粗线 · 速度母题**

| Logo 元素 | 色值 | 语义 | 对界面的约束 |
|-----------|------|------|------------|
| 闭合圆环 | 炭灰 `#2D3436` | 安全 / 收纳 | 深色作"锚定色"（侧栏底属此族） |
| 速度线 | 品牌绿 `#00B894` | 速度 / 高效 | accent 与关键反馈 |
| 书签飘带 | 品牌绿 `#00B894` | 核心=书签 | 线性化为选中态/装饰母题 |
| 高光 | 浅绿 `#55EFC4` | 活力 | 仅点缀 |

**红线**：违背"克制双色 / 几何 / 扁平"即为不统一。

## 2. 颜色体系（Color System）

### 2.1 品牌绿：优先保真，其次达标

**规范判定**：品牌绿以 Logo 原色 `#00B894` 为准。实色按钮**首选保留 `#00B894` 底 + 炭灰 `#2D3436` 文字**（≈4.9:1，达 AA），因为它既过对比度、又忠于 Logo。

> ⚠️ 现状把 solid 底压暗为 `#00755C` + 白字（≈4.7:1），虽过 AA 但**按钮绿明显发暗、背离 Logo**。这是保真度债务（见 §12-D）。仅在无法用炭灰字的深色语境，才退回 `#00755C`+白字。

| Token | 值 | 唯一用途 | 对比度 |
|-------|-----|---------|--------|
| `--primary` | `#00B894` | accent：图标/描边/选中指示/按钮底(配炭灰字) | — |
| `--primary-hover` | `#00A383` | hover | — |
| `--primary-active` | `#008F72` | press | — |
| `--primary-on` | `#2D3436` | **绿底之上的前景**（文字/图标，炭灰） | on 绿 ≈4.9:1 ✓ |
| `--primary-text` | `#007D63` | 浅底上的绿字/链接 | on 白 ≈5.6:1 ✓ |
| `--primary-dark` | `#00755C` | 仅退路：需白字的深绿实色 | 白字 ≈4.7:1 |
| `--primary-light` | `rgba(0,184,148,.1)` | 浅底强调 | — |
| `--primary-focus` | `rgba(0,184,148,.35)` | focus ring | — |

> ⚠️ **禁止** `#00B894` 配**白字**（≈2.58:1 不及格）；绿底白字场景一律换炭灰字或用 `--primary-dark`。

### 2.2 中性 / 反馈色

**规范判定**：浅底上的正文/次文本对比必须 ≥4.5:1。

| Token | 值 | 用途 | on 白对比 |
|-------|-----|------|-----------|
| `--text-primary` | `#0F172A` | 主文本 | 高 ✓ |
| `--text-secondary` | `#475569` | 次文本 | ≈7:1 ✓ |
| `--muted` | `#64748B` | **仅**元信息/占位（非正文） | ≈4.5:1（贴下限）⚠️ |
| `--border-color` | `#E2E8F0` | 边框/分隔 | — |
| `--content-bg` | `#F8FAFC` | 内容区底 | — |
| `--card-bg` | `#FFFFFF` | 卡片底 | — |
| `--danger` | `#EF4444` | 危险/删除（**保持红**） | — |

> ⚠️ `--muted #64748B` 贴 AA 下限，**不得用于长正文**，只用于 12–13px 元信息。`--muted` 与 `--text-secondary` 职责相邻，长期应考虑合并（§12-E）。

### 2.3 「绿色预算」使用纪律（核心）

品牌绿是 accent，不是底色。**每个功能区最多一个"绿色焦点"。**

| 区域 | 绿的角色 | 规则 |
|------|---------|------|
| 内容区 | 唯一主操作按钮 | `#00B894` 底 + 炭灰字 |
| 侧栏 | 仅"当前选中分类"指示 | 3px 竖条 `--primary`，其余降中性 |
| 反馈 | 成功用 Semi `success` | 语义色，勿与品牌绿混 |
| 文字/链接 | `--primary-text` | 浅底可读 |

> 反模式：一区内主操作/次操作/导航/选中全用绿 → 层级坍塌（见 `home-design-review.md` §7.1）。

### 2.4 深色侧栏（锚 Logo 炭灰族）

**规范判定**：侧栏深色必须属 Logo 炭灰 `#2D3436` 族，**不得**沿用 Semi 通用冷黑 `#232429`（偏蓝、与绿相冲）。

| Token | 规范值 | 用途 |
|-------|--------|------|
| `--sidebar-bg` | `#202829` | 主底（比炭灰深一档） |
| `--sidebar-surface` | `#2D3436` | 抬升面：品牌头/选中项/弹层 |
| `--sidebar-border` | `rgba(255,255,255,.08)` | 暖中性 hairline |

> 侧栏内 Semi 组件用 `--semi-color-bg-1/2`，须在 `.semi-always-dark` 同步覆盖到同族炭灰，否则弹层拼色。

## 3. 字体排版（Typography）

### 3.1 字号阶（规范判定：清理半档）

**规范阶**（去掉脏台阶、拉开层级）：

| 语义 | 规范值 | 用途 |
|------|--------|------|
| caption | 12px | 徽章/元信息/段标签 |
| body | **14px** | 正文基准 |
| body-lg | 16px | 内容区主阅读文本（书签名等） |
| title-sm | 20px | 区块标题 |
| title | 24px | 页面 H1 |
| display | 32px | 品牌/营销大标题 |

> ⚠️ 现状为 `xs12 / sm13 / md14 / lg16 / xl20 / 2xl24`：**`sm13` 是脏半档**（12/13/14 三档挤在 2px 内），且缺 32。规范**移除 13px**，新增 32（§12-A）。
> ⚠️ base 14px 对整页 NewTab 偏小：**书签名/描述等主阅读文本用 16px**，14px 仅留给工具型/侧栏密集区。

### 3.2 字体栈（规范判定：补 CJK 回退）

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
  "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Helvetica Neue", Arial, sans-serif;
```

> ⚠️ 现状无显式 CJK 回退，Windows 中文渲染依赖系统猜测（§12-F）。品牌瞬间（"Octane" 文字 / H1）可选几何无衬线（Lexend/Sora），仅限拉丁文。

### 3.3 行高（规范判定：token 化）

| Token | 值 | 用途 |
|-------|-----|------|
| `--lh-tight` | 1.3 | 标题 |
| `--lh-normal` | 1.5 | 正文 |
| `--lh-relaxed` | 1.7 | 长文本/说明 |

> ⚠️ 现状 1.4/1.5/1.6/1.7 散落各文件、无 token，需统一（§12-G）。

## 4. 间距 · 圆角 · 层级

### 4.1 间距（规范：8 基准，保留现状）

`--space-*`：`xs4 / sm8 / md12 / lg16 / xl24 / 2xl32`。规范：以 8 为节奏，微调用 4/12。**现状合理，保留。**

### 4.2 圆角（规范判定：拉开可辨的层级）

**规范阶**：

| Token | 规范值 | 用途 |
|-------|--------|------|
| `--radius-sm` | 8px | 按钮/输入/标签 |
| `--radius-md` | 12px | 卡片/浮层/图标按钮容器 |
| `--radius-lg` | 16px | Modal |
| `--radius-full` | 9999px | 圆形图标按钮 |

> ⚠️ 现状 `sm6 / md8 / lg12`：**sm↔md 仅差 2px，肉眼难辨**，"同类统一一档"失去意义。规范改为 **8 / 12 / 16**，层级可感知、更贴 Logo 圆润（§12-B）。

### 4.3 层级/阴影（扁平优先）

- 卡片默认极轻影、hover 略升；**不得加重**。Semi 浮层统一 `shadow-elevated`。
- 不引入多层拟真阴影（违背 Logo 扁平 DNA）。

---

## 5. 动效（Motion）

| Token | 值 | 用途 |
|-------|-----|------|
| `--transition-fast` | 150ms ease | hover/opacity |
| `--transition-normal` | 200ms ease | 状态切换/浮现 |

- 微交互 150–300ms；用 `transform`/`opacity`，勿动 `width/height`。
- 展开 EaseOut / 收起 EaseIn。
- **速度母题**：关键反馈（跳转已打开 Tab）用横向位移体现"速度"，呼应 Logo，仅关键点用。
- **必须**尊重 `prefers-reduced-motion`。
> ⚠️ 现状部分组件裸写时长（未走 token），新代码须走 token（§12-H）。

---

## 6. 图标（Iconography）

- 功能图标统一用 `@douyinfe/semi-icons`（几何、24×24），避免直接引 SVG。
- **品牌区不用彩色 emoji 当图标**（H1/品牌头用单色线性图标，可 tint）。
- emoji 作为分类/工作区的**用户个性化**选项保留，但须同时提供线性图标组作默认与首选。
- 纯图标按钮必须 `aria-label`；容器圆角 `--radius-md`。

## 7. 组件模式（Component Patterns）

| 组件 | 规范判定 |
|------|---------|
| **主按钮** | `#00B894` 底 + **炭灰字**（`--primary-on`）；每区唯一 |
| **次按钮** | 中性 ghost / borderless，hover 才显品牌色 |
| **工具按钮** | 纯图标 / 最弱 borderless，`--semi-color-text-2` |
| **卡片** | 圆角 `--radius-md`；favicon 回退渐变 `--primary-dark → #1ad6a8`（白字可读，唯一非扁平例外） |
| **导航/列表选中** | active = **左 3px `--primary` 竖条** + 文字提亮 + 极轻中性底；hover = `--semi-color-fill-1`（**不用绿**） |
| **输入 focus** | `--primary-focus`（白底可见） |
| **徽章/圆点** | 绿底配炭灰或白（按对比度取，优先炭灰保真） |
| **行内破坏性操作** | 默认隐藏，hover/focus 浮现；触屏常驻 |
| **空状态** | 文案 + 品牌母题线性图标，勿纯文字 |
| **Modal** | 圆角 `--radius-lg`；主按钮同主按钮规范 |

## 8. 明暗与布局

- **骨架**：深色侧栏（Logo 炭灰族）+ 浅色内容区。此范式正确，保留。
- 品牌色的 Semi token 覆盖须同时覆盖 `html body` 与 `html body .semi-always-dark`。
- 布局：68px 品牌 Rail + `--sidebar-width 222px` 导航侧栏，内容区 `max-width 1720px` 居中；书签网格按 xs/sm/md/lg/xl/xxl 显示 1/1/2/3/4/5 列。

---

## 9. 无障碍（硬性）

| 项 | 标准 | 落地 |
|----|------|------|
| 文本对比 | ≥4.5:1 | 绿字 `--primary-text`；绿底炭灰字 `--primary-on`；退路白字用 `--primary-dark` |
| 绿 on 深底 | — | `#00B894` on `#1a1d21` ≈6.4:1 ✓；换炭灰底后**复核** muted 小字 |
| focus | 可见 ring | `--primary-focus` |
| 图标按钮 | `aria-label` | 必须 |
| 颜色非唯一信息 | 状态不止靠色 | 选中态配竖条+字重；徽章配图标 |
| 动效 | 尊重 reduced-motion | 必须 |
| 危险操作 | 二次确认 | 删除分类需输入短语 |

## 10. Token 架构（规范判定：单一真源）

**规范**：语义层 token（`--primary/--space/--radius/--font/--lh`）是**唯一真源**；Semi 的 `--semi-*` 应在 override 层**派生自**语义 token，而非各自独立取值。改一处即全站生效。

> ⚠️ 现状是**双套并行**（自定义 token 与 `--semi-*` 各自定义），存在漂移风险——例如自定义 `--radius` 与 Semi `--semi-border-radius-*` 可能不一致。规范要求二者对齐/派生（§12-C）。

## 11. Do / Don't 速查

| ✅ Do | ❌ Don't |
|-------|---------|
| 绿按钮 `#00B894` 底 + 炭灰字（保真+达标） | 为达标把绿压暗成 `#00755C` 当默认 |
| `#00B894` 配白字时改用炭灰字 | `#00B894` 直接配白字（2.58:1） |
| 浅底绿字用 `--primary-text` | 用 `--primary` 做浅底文字 |
| 每区一个绿色焦点 | 侧栏按钮全刷绿 |
| 选中态 3px 绿竖条 + 字重 | 只靠 20% 绿底 tint |
| 侧栏底锚 Logo 炭灰族 | 沿用 Semi 冷黑 `#232429` |
| 圆角 8/12/16 拉开层级 | 6/8 两档难辨 |
| 字号 12/14/16/20/24/32 | 保留 13px 脏半档 |
| 语义 token 单一真源 | 双套 token 各自为政 |
| 品牌区线性图标 | H1 放大彩色 emoji |
